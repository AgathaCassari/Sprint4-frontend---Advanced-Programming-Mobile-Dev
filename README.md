# Sistema de Consultas Médicas

## Descrição

Aplicativo mobile desenvolvido em React Native com Expo para gerenciamento de consultas médicas.

## Funcionalidades

- Listar consultas
- Cadastrar consultas
- Visualizar detalhes das consultas

## Tecnologias

- React Native
- Expo
- TypeScript
- React Navigation

## Dados Mockados

Os dados são simulados através do arquivo:

src/data/consultasMock.ts

Não há integração com backend nesta sprint.

## Como executar

npm install

npx expo start
